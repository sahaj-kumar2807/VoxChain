## Brand & Style

This design system expresses high-stakes democratic cryptography through an obsidian-dark, precision-engineered aesthetic. Built for decentralized governance protocols, global voting telemetry, and treasury allocation cycles, the interface channels the solemnity of civic institutions combined with orbital aerospace instrumentation.

### Aesthetic Foundation
- **Obsidian Dark Luxury:** Deep, multi-layered black surfaces eliminate cognitive noise and frame active votes as consequential civic actions.
- **Architectural Constructivism:** Precision hairline structural grids, exposed alignment axes, and meticulous spacing inspire uncompromised trust and cryptographic verifiability.
- **Controlled Kinetic Neon:** Sparse accents of acid-electric lime punctuate critical state changes (voting windows, consensus quorum thresholds, proposal execution alerts), functioning as laser telemetry across an ink-black vacuum.
- **Typographic Dialectic:** Stark, high-contrast grotesque display headlines command institutional gravity, while monospaced metadata counters reinforce raw mathematical transparency.

## Colors

The palette is engineered around pure visual hierarchy in an uncompromising dark spectrum. 

- **Primary (`#D4FF00` - Acid Lime):** Reserved exclusively for active governance state indicators, consensus confirmation, terminal call-to-actions, and live quorum fills.
- **Secondary (`#1C212B` - Deep Hairline Slate):** Used for micro-borders, structural wireframe grids, and dormant divider rules.
- **Tertiary (`#768297` - Muted Telemetry Grey):** Provides high-legibility secondary metadata, epoch counters, and transaction hashes without competing with primary content.
- **Neutral Canvas (`#07080A` - Absolute Obsidian):** The foundational void upon which layered panels (`#0B0D12` and `#12161F`) float.
- **Stark Crisp Text (`#F5F7FA`):** Pure contrast white for primary legislative text, titles, and ballot options.

## Typography

The typographic hierarchy enforces a division between civic policy and machine proof:

- **Display & Headlines:** `Space Grotesk` introduces modern mechanical character with subtle ink traps, imparting authority and structural permanence to proposal headlines and cycle milestones.
- **Body & Interface Copy:** `Hanken Grotesk` delivers neutral, effortless readability for dense governance briefs, amendment breakdowns, and voting rationales.
- **Cryptographic & Telemetry Labels:** `JetBrains Mono` handles all ledger state parameters, block heights, voting power multipliers, countdown timers, and cryptographic addresses. Monospace labels must always be rendered with uppercase tracking (`letter-spacing: 0.08em` to `0.12em`).

## Layout & Spacing

This design system uses a strict 12-column architectural grid framed by expansive perimeter voids. Negative space is deployed intentionally as an indicator of luxury and focus.

### Layout Rhythm
- **Desktop (1440px+):** Max-width containment of `1360px` centered within the obsidian canvas, flanked by generous `margin` (`3rem`) pads and `1.5rem` (`24px`) grid gutters.
- **Tablet (768px – 1024px):** 8-column layout with `2rem` outer margins. Multi-metric voting panels collapse to 2-column modules.
- **Mobile (< 768px):** 4-column layout with tight `margin-mobile` (`1.25rem`) and `1rem` gutters. Monospaced indicators switch to horizontal scrolling strip arrays to protect grid integrity.
- **Grid Superimposition:** Layout sections are separated by continuous 1px horizontal guide rules (`#1C212B`), anchoring content cards directly along grid intersection coordinates.

## Elevation & Depth

In keeping with the tech-luxury aesthetic, elevation rejects blurry drop shadows in favor of surface luminescence, calibrated border contrast, and atmospheric glows.

- **Surface Layer 0 (Base Canvas):** `#07080A` — The terminal background.
- **Surface Layer 1 (Structural Card):** `#0B0D12` with a 1px uniform outline of `#1C212B`.
- **Surface Layer 2 (Active/Hover State):** `#12161F` with a 1px border shift to `#2A3342`.
- **Orbital Telemetry Glows:** Elements with active status (such as open ballot sessions) emit a directional ambient halo: `box-shadow: 0 0 24px -4px rgba(212, 255, 0, 0.18)`.
- **Cryptographic Glass:** Modal overlays and floating governance action drawers leverage `rgba(11, 13, 18, 0.78)` backdrops paired with `backdrop-filter: blur(16px)` and an inner top border highlight of `rgba(245, 247, 250, 0.08)`.

## Shapes

The design system favors engineered precision over playful curvature. Geometry is grounded in architectural softness:

- **Structural Containers & Cards:** Enforce soft geometric corners (`4px` / `rounded-sm`), delivering clean alignment with the 1px grid borders.
- **Interactive Badges & Status Pills:** Standardized at `rounded-sm` or micro-chamfered styling, avoiding full capsule shapes to preserve the high-tech, instrument-grade persona.
- **Orbital Nodes:** Pulsing live-status nodes and voting power charts represent the singular deliberate departure into perfect circles (`border-radius: 9999px`).

## Components

### Buttons
- **Primary Execution (Cast Vote, Propose):** Solid `#D4FF00` background with jet-black `#07080A` typography (`Space Grotesk`, medium weight). Zero border, `4px` corner radius. Hover triggers an orbital ambient glow (`rgba(212, 255, 0, 0.35)`).
- **Secondary (Delegation, Verify Proof):** Transparent base with a 1px `#242B38` border and `#F5F7FA` typography. Hover transforms the border to `#D4FF00` and text to `#D4FF00`.
- **Tertiary Utility:** Monospace ghost button (`JetBrains Mono`, `11px`), uppercase, padded with `space-xs` and `space-sm`.

### Metric Chips & Status Indicators
- **Active Cycle Chip:** `#0B0D12` background, 1px border in `#D4FF00`, featuring a leading 6px glowing indicator dot oscillating with a slow radar pulse. Monospace tracking.
- **Quorum Met:** Subdued deep olive-tint background (`rgba(212, 255, 0, 0.06)`), hairline green border (`rgba(212, 255, 0, 0.2)`), text rendered in `#D4FF00`.

### Cards & Proposal Panels
- Encased in `#0B0D12` with 1px `#1C212B` bounding outlines. 
- Integrated linear quorum tracker: An ultra-thin 2px progress bar spanning the bottom border of the card, filling in `#D4FF00` as voting milestones clear.
- Card headers feature monospaced epoch and cycle indexes (`CYCLE // 084`) docked to the upper right.

### Input Fields & Sliders
- **Token Allocation Inputs:** `#07080A` background with crisp `#1C212B` inset lines. Focused state switches line to `#D4FF00`. Numeric values display in `JetBrains Mono` alongside interactive MAX and locked-governance sliders.
- **Radio & Ballot Checkboxes:** Custom square selectors (`16px`) with 1px borders in `#242B38`. Selected states populate with an interior `#D4FF00` core.

### Orbital Telemetry Gauges
- Specialized visual elements for quorum status, epoch timers, and treasury split ratios: Concentric circular vectors with hairline tracks (`#1C212B`) and glowing `#D4FF00` arc strokes representing current vote participation metrics.
